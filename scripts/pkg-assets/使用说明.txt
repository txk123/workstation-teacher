教师班主任工作台 · 本地服务版（改造版）
========================================

这是什么
--------
基于开源项目「教师班主任工作台」改造的本地服务版：
- 数据不再存浏览器，改存本机 data 目录（每天自动备份，保留最近 30 份）
- AI 请求由本地服务转发，智谱、DeepSeek 等都可以直接用（不受浏览器跨域限制）
- API Key 保存在 app\server\config.json，浏览器页面看不到它
- 双击即用，免安装

怎么用
--------
1. 双击「启动工作台.bat」
2. 浏览器会自动打开 http://127.0.0.1:8788/（若端口被占会自动换下一个，
   以启动窗口里显示的地址为准）
3. 用完直接关掉黑窗口即可，数据不会丢

数据与备份
--------
- 所有数据在 data 文件夹里：换电脑把整个文件夹拷走即可
- 建议定期在应用内「设置 → 数据与备份」导出一份备份文件
- 程序升级不影响数据：新版本第一次启动会自动完成数据格式升级（升级前自动留快照）

AI 接口配置
--------
设置 → AI 接口：选服务商、填 API Key，修改后自动保存。
没配 Key 也能用：生成时会给你提示词，复制到豆包/DeepSeek 网页版即可。
